# DJ 专属网易云音乐下载与歌单管理助手设计规范

本文档为 **DJ 专属网易云音乐下载与歌单管理助手 (DJ NetEase Music Downloader & Manager)** 的架构与功能设计规格说明。

---

## 1. 项目目标与定位

本应用旨在解决 DJ 群体从网易云音乐下载曲库、管理歌单并导入 DJ 软件（如 Rekordbox、Serato DJ、Traktor）时的繁琐流程。

- **核心场景**：
  1. 用户通过官方 API 扫码安全登录网易云账号。
  2. 在应用内查看、新建、删除歌单，向歌单中添加或移出歌曲。
  3. 一键将选中歌单下载导出到统一的本地根目录，**每个歌单自动归类独立文件夹**。
  4. 下载过程中自动完成 **NCM 格式解密** 与 **音频转码**，确保文件夹内**仅保留标准高品质 MP3 文件**。

---

## 2. 核心功能与命名/质量策略

### 2.1 文件结构规范
```text
[用户指定的根目录] (例如 D:\DJ_Music_Library\)
 ├── 歌单 01 - Techno Bounce/
 │    ├── 歌手A - 歌曲1.mp3
 │    └── 歌手B - 歌曲2.mp3
 ├── 歌单 02 - Deep House/
 │    ├── 歌手C - 歌曲3.mp3
 │    └── 歌手D - 歌曲4.mp3
 └── ...
```

### 2.2 命名与质量规则
- **文件命名规则**：`歌手名 - 歌曲名.mp3`（保留原始清晰文件命名格式）。
- **音频质量策略**：
  - 自动保留源音频最高音质（无损 FLAC / 320kbps MP3 等）。
  - 若为无损 FLAC 或 NCM 解密出来的无损音频，FFmpeg 将以 **最佳品质 (320kbps CBR/VBR 0)** 压制为 MP3，确保与所有 DJ 设备与闪存盘 100% 兼容。
- **只留 MP3 策略**：歌单文件夹中仅存储与输出 `.mp3` 格式文件，任何中间临时文件（`.tmp` / `.ncm`）处理后自动清理。
- **跳过增量**：若歌单文件夹中已存在目标 `.mp3` 文件且体积正常，自动跳过重复下载。

## 3. 系统架构设计

系统采用 **桌面端应用架构 (Tauri / Electron)**：

```
+-------------------------------------------------------------------+
|                        Web 前端 UI 界面                            |
| (扫码登录 | 歌单 CRUD | 歌曲增删 | 根目录设置 | 批量导出进度条)         |
+-----------------------------------+-------------------------------+
                                    | IPC 接口 / HTTP
+-----------------------------------v-------------------------------+
|                      后台核心引擎 (Rust / Node.js)                 |
|                                                                   |
|  [网易云 API 模块]    [NCM 解密引擎]    [FFmpeg 转码与 ID3 标签模块] |
|   - 扫码 Auth          - Magic Header    - 音源压制 320k MP3       |
|   - 歌单管理           - AES-128 解密    - 写入歌名/歌手/封面       |
|   - 曲目获取           - RC4 还原音频                               |
|                                                                   |
|  [目录导出与文件管理]                                              |
|   - 根路径匹配 -> 创建歌单文件夹 -> 校验去重 -> 写入标准 MP3       |
+-------------------------------------------------------------------+
```

## 4. 模块细节

### 4.1 用户认证与歌单管理
1. **扫码登录**：生成网易云官方二维码，前端定时轮询登录状态，成功后持久化 Cookie。
2. **歌单操作**：
   - 歌单列表：展示创建的歌单与收藏的歌单。
   - 新建歌单：支持指定歌单名称与公开/隐私属性。
   - 删除歌单：确认后同步删除网易云账号下该歌单。
   - 歌曲增删：从搜索列表或其它歌单将歌曲添加到当前歌单，或从当前歌单移除。

### 4.2 解密与转码流水线
1. **下载**：获取最高音质歌曲 URL。
2. **校验**：判断是否为 `.ncm` 加密。
3. **解密**：若为 `.ncm`，调用纯原生解密引擎，还原出原始音轨（MP3 或 FLAC）与歌曲元数据（ID3 标签）。
4. **转码**：若原始音轨为 FLAC / WAV，FFmpeg 自动压制为 320kbps MP3。
5. **ID3 写入**：使用 `id3` 标签库，将歌曲名、歌手、专辑、封面图片注入生成的 `.mp3` 文件中。
6. **落盘**：写入至 `<RootDir>/<PlaylistName>/<Artist> - <Title>.mp3`。

---

## 5. 验证与质量保证

1. **解密准确性**：单元测试验证 NCM 解密结果与源文件完全一致。
2. **转码兼容性**：转码后的 MP3 经过 ID3v2 校验，可无缝拖入 Rekordbox 及 Serato DJ 中识别 BPM 与 Album Cover。
3. **异常处理**：网络中断时支持重试，非法字符歌单名自动过滤（如替换 `\ / : * ? " < > |` 为 `_`）。
