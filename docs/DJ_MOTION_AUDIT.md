# DJ 工作台交互与动效盘点

统计范围：`/dj/` 主界面及其弹层，来源为 `renderer/src/main.ts`、`renderer/src/workbench.ts`、`renderer/src/dj-agent.ts` 的模板与事件处理。静态模板中可识别 85 个命名动作（主界面 25、工作台 38、Agent 22）；另有按状态生成的动作，因此这个数字是代码入口数，不等于页面上的按钮数。

| 交互域 | 入口与关键状态 | 本轮动效规则 |
| --- | --- | --- |
| 启动和 3D 档案 | 进入/跳过、重播、拖动和滚轮选档、歌曲/歌单档案、360° 浏览 | 保留原仓库启动与 3D 镜头动画；叠层开启时背景平滑失焦，导出时保留档案聚焦与清晰展示 |
| 工作台导航 | 4 个主入口：AI DJ、云端歌单、在线搜索、导出根目录 | 选中轨道在原位伸展；箭头只移动 4px；不移动按钮布局 |
| 右侧面板 | Agent、云端歌单、在线搜索 3 种面板；关闭按钮和左侧空白区收回 | 右侧滑入 420ms、滑出 300ms，可从中断位置反向；铜色顶线与面板同步出现；保持左侧 UI |
| 云端歌单 | 列表、搜索、刷新、新建、详情、播放、增删曲目、导出确认与进度 | 卡片操作始终可见；悬停只强化边线、封面；确认框短距离进入；导出进度连续推进 |
| 在线搜索 | 输入、查询、结果播放与加入歌单 | 输入焦点显示细铜线；结果行仅改变底色，操作按钮短按反馈 |
| Agent | 会话切换/新建/重命名/删除、提示词、消息输入、模型配置、发送/停止、结果卡片 | 统一按钮 90ms 按下反馈与 180ms 回位；提示词箭头短移；重绘时保留关闭按钮焦点 |
| 播放器 | 封面打开 3D 档案、播放/暂停、上一首/下一首、拖动进度、下载与加入歌单 | 卡片铜线指向可打开区域；拖动点放大；加载方点闪烁、播放方点常亮；状态文字可朗读 |
| 账号和设置 | 二维码、验证、授权成功、手动 Cookie、登出、动态效果偏好 | 授权环在成功时只运行一次后静止；减少动态效果时立即呈现最终状态 |

## 动效语言

- 终端感来自细线、状态方点、铜色信号路径；保留大量静止留白。
- 即时按压为 90ms，悬停和焦点反馈为 180ms，常规进入为 320ms，面板进入为 420ms。进入使用 `cubic-bezier(.16,1,.3,1)`，退出使用 `cubic-bezier(.7,0,.84,0)`。
- 连续位移优先使用 `transform` 和 `opacity`；歌单/搜索行只改变颜色与边线，避免列表重排。进度条采用 `scaleX`，从上一个可见值过渡到新值。
- 动效不能作为唯一状态提示：选中、加载、错误、完成依然要有文字或可访问状态；歌单卡片操作在触摸设备与键盘浏览时可见。
- 系统 `prefers-reduced-motion` 和页面的“减少动态效果”开关会跳过新增动效。

## 验收路径

1. 进入工作台后分别打开三种右侧面板，快速切换和中途关闭，面板位置连续，不闪回；左侧播放器与时间保持原位。点击左侧空白区收回，焦点返回原入口。
2. 键盘聚焦导航、歌单操作、搜索和 Agent 控件时能看到焦点框；Agent 初次载入会话后关闭按钮仍持有焦点。
3. 歌单卡片不悬停时也能看到播放/导出操作；触摸模式下不依赖悬停。导出状态更新时进度条连续，不倒退、不超过 100%。
4. 播放器加载/播放/暂停、拖动进度、上一首/下一首有对应可见反馈；暂停后不保留“加载中”闪烁。
5. 授权成功后二维码切换为成功标志，环形动效完成后静止。打开减少动态效果时，面板和确认框即时切换。
6. 在桌面及窄屏检查面板可用性、滚动可达性和控制台错误；不修改真实账号或执行导出即可验证动效与基础路径。

实现集中在 `renderer/src/dj-motion.css`；面板、导出进度和播放器状态的连续性逻辑在 `renderer/src/workbench.ts`，Agent 重绘焦点保持在 `renderer/src/dj-agent.ts`。
